* Pivoting
- *moving to other networks through compromised host to find more targets on diff network segments*
- defeat segmentation (phys & virt) to access isolated network

** IP Addressing & NICs
- IP assigned through DHCP server or static to NIC

** Routing
- ~netstat -r~ / ~ip route~ -> routing table

* Tunneling
- subset of pivoting
- encapsulates network traffic into another protocol and routes traffic through it
- eg: *VPN*
