* Remote Password attacks
** Network Services
*** WinRM
- based on XML web srv based on =SOAP= (=Simple Object Access Protocol=)
- takes cRe of comms b/w =Web-Based Enterprise Mgmt= (=WBEM=) & =Windows Mgmt Instrumentation= (=WMI=), which can call =Distributed Component Object Model= (=DCOM=)
- port =TCP 5985= (HTTP) / =TCP 5986= (HTTPS)

**** NetExec
- can also be used for SMB, LDAP, MSSQL etc
-

****** Usage
- ~netexec <protocol> <target-ip> -u <user or userlist> -p passwd.list~

**** Evil-WinRM
- efficient communication w WinRM service

****** Usage
- ~evil-winrm -i 10.129.42.197 -u <user> -p <password>~

*** SSH
**** Symmetric Encryption
- same key for enc/dec => key xchange procedure required (DH)
**** Asymmetric Encryption
- pub, pvt keys
**** Hashing
- converts transmitted data into another unique val
- used to confirm authenticity of messages.
- mathematical algo _c_ works only in one dir

****** HYDRA - SSH
~hydra -l user.list -P password.list ssh://<ip>~

*** RDP
- =TCP 3389=

**** Hydra
~hydra -L user.list -P password.list rdp://<ip>~

*** SMB

**** Hydra
- ~hydra -L user.list -P password.list smb://<ip>~

**** Metasploit
- =auxiliary/scanner/smb/smb_login=

**** NetExec
- view avl shares, privileges
- ~netexec smb 10.129.42.197 -u "user" -p "pass" --shares~

** Password Spraying
- brute force -> attempt to use single password accross many diff users
- v effective when users init w default/std pass
- =Burp Suite= -> webapps
- =NetExec= / =Kerbrute= -> AD

** Credential Stuffing
- brute force -> stolen creds from one service attempted on others
- =hydra= -> ~hydra -C user_pass.list ssh://<ip>~
