#+title: virtualisation


* Security
- Support secure and dynamic environments of organisations with:
  1. Increased operational efficiency
  2. Reduced capital investments in hardware
- Negligence of security creates new set of security challenges and risks to organisations

* Risk
** VM Sprawling
- Number of VMs increase to point where the admin can no longer manage effectively
- Can potentially increase number of unpatched VMs in network env.
** Sens data within VM
- abilitty to move VMs accross network puts data in VM at risk.
** Security of preconf/active VMs
- attacker can tweak settings of preconf/active VMs by gaining unauth access to platform on which VMs are hosted.
** Resouce Exhaustion
- Overallocation of virtual envs -> significant performance degradation.
** Hypervisor
security of dev can be changed on Hypervisor.
** Workloads of diff trust level on same server
** cloud service provider APIs

* Approaches
** Full Vt
#+begin_quote
guest OS not aware of vt
#+end_quote
- sends command to VMM to interact with computer hardware
- VMM translates commands to binary and forwards to host OS
** ParaVt
#+begin_quote
Guest OS aware of virt env. communicates with host machine to request resources.
#+end_quote
- commands translated into bin code by guest for computer hardware. (VMM not involved)
** Hardware assisted
- special instr to aid vt of hardware
- enable guest OS to exec privileged instr directly on processor
- host OS treats sys calls as user programs
** Storage dev vt
#+begin_quote
vt of storage devs using data striping and data mirroring
#+end_quote>
- eg: RAID
** FS Vt
- facilitates convenience of sharing and protection of data withing software
- vt data pools manipulate files & data based on user demand
** Server Virtualisation
#+begin_quote
enables partition of server's OS env
#+end_quote>
- involves logical partitioning of server's HDD
** Fabric
#+begin_quote
Makes vt dev independent of phys computer hardware
#+end_quote>
- creates massive pool of storage areas for different VMs running on hardware
- SAN (storage area network) tech used to achieve fabric-level vt

* Network VT
- Combine avl network resources and share amongst network users using single admin unit
- Combine multiple physical networks into one virtual, software based network. || Divide phys net into separate independent virtual network.
- NV splits avl bandwidth into independent channels.
  can be assigned to server in real-time
** Internal VN
#+begin_quote
Virtual networking takes place inside virtual servers to create logical networks between VMs.
#+end_quote
