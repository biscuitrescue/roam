** SDN (software def arch)
*** App Layer
- Includes network and services which interact with sdn controller
- support functionalities such as:
  - routing
  - traffic engineering
  - security
*** controller layer
- controller acts as central control entity of network
- maintains global view of network
- translates application req into network policies
- communicates policies to underlying networking devs
*** net dev layer
- forwarding devs:
  - switches
  - routers
- exec packet fwding & data processing
** Core components
*** Data Plane
Responsible for forwarding packets based on flow table entries installed by controller
*** Control Plane
Represents logical view of network
Responsible for making fwding and policy decisions
*** Application Plane
Hosts network application such as:
- routing protocols
- load-balancers
- monitoring systems
- security services
*** Northbound API
interface b/w controller and application layer.
enables apps to req network services and policies
*** Southbound API
comms b/w controller and networking devs.
allows controller to install and update flow rules
*** OpenFlow Protocol
enables comms in southbound interface b/w controller and fwding devs.
