* Dynamic Port Fwding w SSH & SOCKS Tunneling 

** Port Fwding
- redirect communication request from 1 port to another
- TCP = primary communcation layer to provide interacting
- different application layer protocols (SSH) or non application layer protocols (SOCKS) can be used to encapsulate fwded traffic
- effective in bypassing firewalls & using existing srvs on host to pivot to other networks

*** SSH Local Port Fwding

**** Executing Local Port Fwd
- ~ssh -L 1234:localhost:3306 ubuntu@10.129.202.64~

**** Confirm Port Fwd (Netstat)
- ~netstat -antp | grep 1234~

**** Confirm Port Fwd (NMAP)
- ~nmap -v -sV -p1234 localhost~

*** Enabling Dynamic Port Fwding w SSH
- ~ssh -D 9050 ubuntu@<ip>~
- =-D= -> enable dynamic port fwd
- =proxychains= to route any tool's packets over port =9050=
  - =/etc/proxychains.conf= -> ~socks4 127.0.0.1 9050~

*** Nmap w Proxychains (SOCKS Tunneling)
- ~proxychains nmap -v -sn 172.16.5.1-200~
- can only perform *full TCP Connect scan*

*** Enumerating win target w Proxychains
